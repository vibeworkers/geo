# geo-report — GEO 종합 보고서 생성

> 실행 시 USER_LEVEL을 확인한다. 설정되지 않은 경우 레벨 선택을 먼저 요청한다.
> 보고서 언어: OUTPUT_LANG에 따라 작성한다 (ko=한국어·기본, en=영어, ja=일본어, zh=중국어, es=스페인어).
> 파일명: OUTPUT_LANG=ko → `GEO-종합보고서.md` / 그 외 → `GEO-report-[OUTPUT_LANG].md`

---

## geo-audit와의 관계

| 스킬 | 역할 |
|---|---|
| geo-audit | 5개 영역 분석을 오케스트레이션하고 종합 GEO 점수 산출 |
| geo-report | 분석 결과를 수신자(레벨)에 맞는 보고서 형태로 재구성·저장 |

geo-audit 직후 실행하면 최신 분석 결과를 반영한다.
단독 실행 시에는 현재 폴더의 `GEO-*.md` 파일을 읽어 취합한다.

---

## 실행 단계

### 1단계: 분석 결과 수집

현재 작업 폴더에서 기존 분석 파일을 읽는다.

```
읽기 대상 파일 (존재하는 경우):
- GEO-감사-보고서.md
- GEO-콘텐츠-분석.md
- GEO-인용가능성-분석.md
- GEO-크롤러-분석.md
- GEO-브랜드언급-분석.md
- GEO-플랫폼-분석.md
```

파일이 없는 경우: 사용자에게 먼저 `/geo audit [URL]`을 실행하도록 안내한다.

---

### 2단계: 점수 취합

각 분석 파일에서 점수를 추출하고 종합 GEO 점수를 계산한다.

```
종합 GEO 점수 = (인용 점수 × 0.25) +
               (크롤러 점수 × 0.20) +
               (콘텐츠 점수 × 0.20) +
               (기술 점수 × 0.15) +
               (스키마 점수 × 0.10) +
               (플랫폼 점수 × 0.10)
```

분석 파일이 일부만 있는 경우: 존재하는 점수만 사용하고 누락 항목을 명시한다.

**점수 등급표**

| 점수 | 등급 | 상태 |
|---|---|---|
| 80–100 | 우수 | AI 검색 최적화 상위 수준 |
| 60–79 | 양호 | 기본 최적화 완료, 개선 여지 있음 |
| 40–59 | 보통 | 주요 개선 과제 다수 존재 |
| 20–39 | 미흡 | 즉각적인 조치 필요 |
| 0–19 | 위험 | AI/search readiness 신호가 매우 부족함 |

---

### 3단계: 개선 과제 우선순위 정렬

각 분석에서 도출된 개선 과제를 geo-audit 심각도 분류 기준에 맞춰 4단계로 정렬한다.

| 심각도 | 기준 | 처리 기한 |
|---|---|---|
| **CRITICAL** | AI 크롤러 전면 차단, 순수 CSR, HTTPS 미적용, noindex 설정 | 1주 이내 |
| **HIGH** | 주요 봇 차단, llms.txt 없음, Organization 스키마 없음, 저자 정보 없음 | 1달 이내 |
| **MEDIUM** | llms.txt 불완전, sameAs 부족, dateModified 없음, 내부 링크 부족 | 3달 이내 |
| **LOW** | OG 불완전, alt 일부 없음, FAQ 구조 없음, 마이너 기술 이슈 | 순차 개선 |

> CRITICAL 항목이 1개라도 있으면 총점이 높아도 실질적인 AI 가시성은 낮다. 보고서 상단에 경고 배너를 출력한다.

---

### 4단계: 레벨별 보고서 작성 및 저장

아래 출력 템플릿에 따라 보고서를 작성하고 OUTPUT_LANG에 맞는 파일명으로 저장한다.

> **OUTPUT_LANG 출력 규칙**
> - 섹션 제목·설명·권고사항·등급명을 OUTPUT_LANG으로 번역하여 작성한다.
> - 기술 용어(URL, robots.txt, JSON-LD, Core Web Vitals 등)는 언어와 무관하게 원문 유지한다.
> - OUTPUT_LANG=ko: 기존 한국어 템플릿 그대로 사용 (기본값).
> - OUTPUT_LANG=en/ja/zh/es: 섹션 제목과 본문을 해당 언어로 작성하되 구조는 동일하게 유지한다.
