# geo-brand — AI 브랜드 인식 Gap 추적

> 실행 시 USER_LEVEL을 확인한다. 설정되지 않은 경우 레벨 선택을 먼저 요청한다.
> 분석 결과는 USER_LEVEL에 맞는 출력 템플릿으로 전달한다.
> `GEO-BRAND-GAP-*.md` (메인 보고서), `GEO-BRAND-CP-인풋-*.md` (CP 투입), `GEO-BRAND-BASELINE-*.json` (추적 데이터) 생성.

---

## 명령어 형식

```bash
# 최초 측정 — Gap 분석 + CP 인풋 생성
/geo brand <url> [--brand <브랜드명>] [--segments "<s1,s2,s3>"] [--competitors "<c1,c2>"] [--comp <positioning.md경로>]

# 4주 후 재측정 — 변화 추적
/geo brand <url> --track
```

### 인수 설명

| 인수 | 필수 | 설명 |
|------|------|------|
| `<url>` | 필수 | 분석 대상 도메인 |
| `--brand` | 권장 | 브랜드명 (미입력 시 도메인에서 자동 추출) |
| `--segments` | 선택 | 타겟 세그먼트 3개, 쉼표로 구분 (미입력 시 사업 유형 기반 자동 생성) |
| `--competitors` | 선택 | 비교할 경쟁사명, 쉼표로 구분 |
| `--comp` | 선택 | Tunnel COMP의 competitive-positioning.md 경로 |
| `--track` | 선택 | 이전 측정과 비교해 변화 출력 |

## 처리 흐름 — 4 Phase

### Phase 1: 데이터 수집

#### 1-1. 포지셔닝 기준 확보

우선순위 순서로 "우리가 원하는 포지셔닝"을 확보한다.

```
① --comp 플래그로 competitive-positioning.md 지정 → 파싱
② 현재 디렉토리의 GEO-*.md, competitive-positioning.md 자동 탐색
③ 없을 경우: URL 홈페이지 + 메타 텍스트에서 포지셋닝 키워드 추출
```

추출할 정보:
- 우리가 강조하는 포지셔닝 키워드 (예: "AI 기반 마케팅 자동화 1위")
- 타겟 세그먼트 정의
- 차별화 주장 (경쟁사 대비 강점)

#### 1-2. AI 담변 수집

프롬프트 자동 생성:
- `--segments` 지정 시: 입력된 세그먼트 3개 사용
- 미입력 시: 사업 유형 × 의도(정보·비교·결정) 조합으로 자동 생성

예시:
```
세그먼트 3개: "신규 사용자", "기존 사용자", "경쟁사 비교 검토"
의도 3가지: 정보 탐색, 비교 검토, 구매 결정
결과: 9개 프롬프트 자동 생성
```

browser-citation 연계:

```bash
/browser-citation --domain <domain> --keywords "<9개 프롬프트>" \
  --brand "<브랜드명>" --mode aiba --platforms "chatgpt,perplexity,gemini"
```

환경별 처리:

**Claude Code (CDP 포트 9222 접속 가능)**
```
자동 수집 실행
→ ChatGPT·Perplexity·Gemini 담변 수집 (최대 27개)
```

**Claude Code (Chrome 미실행)**
```
메시지: "Chrome CDP를 먼저 시작하세요"
제안: /browser-citation --headed 실행 후 재시도
```

**Claude 웹**
```
9개 프롬프트 목록 출력
사용자에게 각 AI 플랫폼에서 직접 질문 후 담변 붙여넣기 요청
```

수집 데이터:
- 담변 텍스트 전문
- 브랜드 등장 여부 + 맥락 문장
- 인용 URL 목록
- 경쟁사 동반 등장 여부

### Phase 2: Gap 분석

원하는 포지셔닝과 실제 AI 인식의 차이를 5가지 실측 지표로 계산한다.

#### 5가지 실측 지표

| 지표 | 계산 방식 | 만점 | 의미 |
|------|---------|------|------|
| **포지셔닝 반영률** | 원하는 키워드 등장 담변 수 / 전체 담변 수 × 100 | 100 | Gap의 직접 지표 |
| **SOV** | 브랜드 등장 담변 수 / 전체 담변 수 × 100 | 100 | 노출 점유율 |
| **BCI** | 단독 등장 수 / 전체 등장 수 × 100 | 100 | 단독 브랜드 인식 강도 |
| **채널 인용률** | 자사 URL 인용 수 / 전체 인용 URL 수 × 100 | 100 | 우리 콘텐츠 도달도 |
| **맥락 일치율** | 원하는 속성 클러스터 매칭 비중 / 9 × 100 | 100 | 브랜드 이미지 정확도 |

#### Gap 등급 (포지셜닝 반영률 기준)

| 등급 | 명칭 | 반영률 | 의미 |
|------|------|--------|------|
| INVISIBLE | 미인식 | 0~20 | AI가 우리 포지셔닝을 전혀 반영하지 않음 |
| DISTANT | 괴리 | 21~40 | 우리 인식과 AI 인식 큰 차이 |
| PARTIAL | 부분 일치 | 41~60 | 일부 반영, 핵심 메시지 누락 |
| ALIGNED | 정합 | 61~80 | 포지셔닝 대부분 반영됨 |
| ANCHORED | 완전 정합 | 81+ | 저장된 답변 샘플에서 포지셔닝 반영 신호가 강함 |

### Phase 3: 콘텐츠 연결

Gap 분석 결과를 `/cp prep`에 즉시 투입 가능한 형태로 변환한다.

#### Gap → 콘텐츠 주제 자동 변환

```
Gap: "자동화" 키워드가 AI 담변에서 우리와 연결되지 않음
→ 콘텐츠 주제: "마케팅 자동화 도구 비교: [브랜드]가 선택되는 이유"
→ 목표 프롬프트: "마케팅 자동화 툴 추천해줘"
→ 기대 반응: 해당 키워드에서 우리 브랜드 단독 인용

Gap: 자사 채널 인용 0%
→ 콘텐츠 유형: FAQ 페이지 신설 + 전문 블로그 포스트
→ 구조 개선: FAQ 스키마 추가, 요약 문단 강화
```

출력 파일: `GEO-BRAND-CP-인풋-[날짜].md`

```markdown
# CP 인풋 — [브랜드명] Gap 해소 콘텐츠 계획

## Gap 우선순위 (Top 3)

   → 기대 효과: [목표]

2. ...
```

### Phase 4: 순환 추적 (`--track` 모드)

4주 전 측정 데이터와 비교해 Gap 변화를 추적한다.

#### 측정 스냅샷 저장

첫 실행 시 `GEO-BRAND-BASELINE-[YYYYMMDD].json` 생성:

```json
{
  "brand": "브랜드명",
  "date": "2026-05-07",
  "url": "https://example.com",
  "positioning_reflection": 32,
  "sov": 18,
  "bci": 24,
  "channel_citation": 0,
  "context_match": 44,
  "gap_grade": "DISTANT",
  "top_gaps": ["자동화 키워드 미연결", "자사 채널 인용 0%"]
}
```

#### `--track` 실행 — 변화 비교

이전 BASELINE 자동 탐색 후 비교:

```
[ Gap 변화 추적 ]
측정 기간: 2026-05-07 → 2026-06-04 (28일)

                    이전      현재      변화
포지셔닝 반영률     32        51       +19 ↑
SOV                 18%       27%      +9% ↑
BCI                 24        38       +14 ↑
채널 인용률         0%        8%       +8% ↑
Gap 등급            DISTANT → PARTIAL  (1단계 개선)

개선된 Gap:
✓ "자동화" 키워드 → 담변 6건 중 3건에서 우리와 연결됨

남은 Gap:
→ 자사 채널 인용률 여전히 낮음 (8%, 목표 30%)
→ 추가 권고: [콘텐츠 주제 2개]
```

새로운 스냅샷으로 BASELINE 갱신:

```json
{
  "brand": "브랜드명",
  "date": "2026-06-04",
  "url": "https://example.com",
  "positioning_reflection": 51,
  "sov": 27,
  "bci": 38,
  "channel_citation": 8,
  "context_match": 67,
  "gap_grade": "PARTIAL",
  "top_gaps": ["자사 채널 인용률 8%", "단독 BCI 38"]
}
```

## 주의사항

- `--track` 실행 시 최근 BASELINE 파일 자동 탐색. 없으면 에러 메시지 출력 후 중단.
- `--comp` 플래그로 positioning.md 지정 시, 그 파일의 포지셔닝 정의를 Gap 분석의 기준점으로 사용.
- browser-citation 미지원 환경에서는 수동 입력 모드로 자동 전환. 프롬프트 목록 출력 후 사용자 붙여넣기 요청.
- 생성된 CP-인풋 파일은 `/cp prep`에 투입하기 전에 검토 필수 (순서·우선순위 확인).
