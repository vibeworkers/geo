# Glossary

## GEO

Generative Engine Optimization. In this package, GEO means improving the
readiness of public web content for AI answer, search, and citation workflows.

## SEO

Search Engine Optimization. In this package, SEO remains the technical and
content foundation that GEO builds on.

## USER_LEVEL

The user profile that controls output packaging, not analysis depth. Supported
values are `L1`, `L2`, and `L3`.

## OUTPUT_LANG

The requested report language. The package keeps technical tokens such as URL,
JSON-LD, schema type names, and command names unchanged.

## Core Workflow

A workflow that can be understood and routed from the shared package without
local shell or browser automation.

## Extension Workflow

A workflow that requires local runtime capabilities such as Bash, Playwright,
browser automation, or local files.

## Readiness Signal

Evidence that a site is better prepared for AI discovery or citation. It is
not the same as observed AI visibility.

## Observed Citation

Evidence from a captured AI answer showing that a specific platform cited a
specific source URL at a specific time.
