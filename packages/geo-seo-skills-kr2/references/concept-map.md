# Concept Map

## Package Path

`geo-seo-skills-kr2` packages the source bundle into a portable skill surface.

`SKILL.md` routes package-level requests to the representative workflow and
execution subskills.

`geo/SKILL.md` preserves the original `/geo` command contract.

`skills/*/SKILL.md` execute focused GEO/SEO workflows.

`references/*.md` preserve durable platform, language, hreflang, and package
boundary notes.

## Workflow Path

User request selects a mode.

Mode selects the representative workflow or a concrete subskill.

Subskill inspects public evidence or local runtime evidence.

Evidence receives a label: measured, readiness, heuristic, or fallback.

Output profile shapes the delivery for L1, L2, or L3.

## Runtime Path

Core workflows stay shared and portable.

Extension workflows declare runtime requirements before use.

Missing runtime support produces a manual fallback or a stop condition.
