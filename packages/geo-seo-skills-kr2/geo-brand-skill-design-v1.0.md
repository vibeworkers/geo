# `/geo brand` 스킬 설계안 v1.0

**작성일:** 2026-05-07
**위치:** geo-seo-skills-kr 15번째 스킬

---

## 설계 원칙 — 함샤우트와 다른 이유

함샤우트는 "현재 AI가 우리를 어떻게 보는가"를 1회 진단하고 권고로 끝낸다.

```
함샤우트:  진단 → 권고 → 끝
/geo brand: Gap 발견 → 콘텐츠 생성 → 4주 후 Gap 축소 검증 → 반복
```

**3가지 차별화 원리:**

1. **Gap 분석** — COMP 포지셔닝(원하는 인식) vs 실제 AI 담변(현재 인식)의 차이를 수치화
2. **콘텐츠 연결** — Gap을 메울 콘텐츠 주제를 자동 생성 → `/cp prep`에 즉시 투입
3. **순환 추적** — 4주마다 재측정해 ΔSoV·ΔBCI 변화 추적, CP 실행 효과 검증

---

## 명령어

```bash
# 최초 측정 (Gap 분석 + CP 인풋 생성)
/geo brand <url> [--brand <명>] [--segments "<s1,s2,s3>"] [--competitors "<c1,c2>"] [--comp <positioning.md>]

# 4주 후 재측정 (변화 추적)
/geo brand <url> --track
```

| 인수 | 필수 | 설명 |
|------|------|------|
| `<url>` | 필수 | 분석 대상 도메인 |
| `--brand` | 권장 | 브랜드명 (미입력 시 도메인에서 자동 추출) |
| `--segments` | 선택 | 타겟 세그먼트 3개 (미입력 시 사업 유형 기반 자동 생성) |
| `--competitors` | 선택 | 비교 경쟁사명 |
| `--comp` | 선택 | Tunnel COMP의 competitive-positioning.md 경로 (Gap 정밀화) |
| `--track` | 선택 | 이전 측정과 비교해 변화 출력 |

## 처리 흐름 — 4 Phase

### Phase 1: 데이터 수집 (자동)

**1-1. 포지셔닝 기준 확보 — Gap 분석의 기준점**

우선순위 순서로 확보:
```
① --comp 플래그로 competitive-positioning.md 지정 → 파싱
② 현재 디렉토리의 GEO-*.md, competitive-positioning.md 자동 탐색
③ 없을 경우: URL 홈페이지 + 메타 텍스트에서 "우리가 강조하는 가치" 추출
```

추출 내용:
- 원하는 포지셔닝 키워드 (예: "AI 기반 마케팅 자동화 1위")
- 타겟 세그먼트 정의
- 차별화 주장 (경쟁사 대비 강점)

**1-2. AI 담변 수집 — 실측**

프롬프트 자동 생성: 세그먼트 3개 × 의도 3가지(정보·비교·결정) = 9개

browser-citation 연계:
```bash
/browser-citation --domain <domain> --keywords "<9개 프롬프트>" \
  --brand "<브랜드명>" --platforms "chatgpt,perplexity,gemini"
```

수집 데이터:
- 담변 텍스트 전문 (최대 27개)
- 브랜드 등장 여부 + 맥락 문장
- 인용 URL 목록 (자사 채널 vs 외부)
- 경쟁사 동반 등장 여부

환경 분기:
```
Claude Code + Chrome CDP 9222 접속 가능  →  자동 수집
Chrome 미실행                            →  "--headed 먼저 실행하세요" 안내
Claude 웹 환경                           →  9개 프롬프트 출력 + 사용자 붙여넣기 요청
```

### Phase 2: Gap 분석 — 핵심 차별화

**원하는 인식 vs AI의 실제 인식 비교**

```
원하는 포지셔닝 (Phase 1-1 추출)
    "우리는 AI 기반 마케팅 자동화의 선두주자"

실제 AI 인식 (담변 추출)
    "해당 카테고리 브랜드 중 하나, 자동화보다 분석 도구로 인식"

Gap
    ① "자동화" 키워드가 AI 담변에서 우리와 연결되지 않음
    ② 경쟁사와 함께 등장, 단독 인식 약함
    ③ 자사 채널 인용 0% → 우리 콘텐츠가 AI에 도달하지 않음
```

**5가지 실측 지표 (0~100)**

| 지표 | 계산 방식 | 의미 |
|------|---------|------|
| **포지셔닝 반영률** | 원하는 키워드 등장 담변 / 전체 담변 × 100 | Gap의 직접 지표 |
| **SOV** | 브랜드 등장 담변 수 / 전체 담변 수 × 100 | 노출 점유율 |
| **BCI** | 단독 등장 수 / 전체 등장 수 × 100 | 단독 브랜드 인식 강도 |
| **채널 인용률** | 자사 URL 인용 / 전체 인용 URL × 100 | 우리 콘텐츠 도달도 |
| **맥락 일치율** | 원하는 속성 클러스터 매칭 / 9 × 100 | 브랜드 이미지 정확도 |

**Gap 등급 (포지셔닝 반영률 기준)**

| 등급 | 명칭 | 반영률 | 의미 |
|------|------|--------|------|
| INVISIBLE | 미인식 | 0~20 | AI가 우리 포지셔닝을 전혀 반영하지 않음 |
| DISTANT | 괴리 | 21~40 | 우리 인식과 AI 인식 큰 차이 |
| PARTIAL | 부분 일치 | 41~60 | 일부 반영, 핵심 메시지 누락 |
| ALIGNED | 정합 | 61~80 | 포지셔닝 대부분 반영 |
| ANCHORED | 완전 정합 | 81+ | AI가 우리 포지셔닝을 정확히 전달 |

> 함샤우트의 GHOST~ANCHOR는 **"현재 인식 수준"**을 봄.
> 우리의 INVISIBLE~ANCHORED는 **"원하는 방향과의 차이"**를 봄.

### Phase 3: 콘텐츠 연결 — CP 자동 인풋

Gap 항목 → 콘텐츠 주제 자동 변환:

```
Gap: "자동화" 키워드가 AI 담변에서 우리와 연결되지 않음
→ 콘텐츠 주제: "마케팅 자동화 도구 비교: [브랜드]가 선택되는 이유"
→ 목표 프롬프트: "마케팅 자동화 툴 추천해줘"
→ 기대 반응: 해당 키워드에서 우리 브랜드 단독 인용

Gap: 자사 채널 인용 0%
→ 콘텐츠 유형: FAQ 페이지 신설 + 전문 블로그 포스트
→ 구조 개선: FAQ 스키마 추가, 요약 문단 강화
```

출력 파일: `GEO-BRAND-CP-인풋-[날짜].md`

```markdown
# CP 인풋 — [브랜드명] Gap 해소 콘텐츠 계획

## Gap 우선순위 (Top 3)
1. [Gap 설명] → [콘텐츠 주제] → [목표 프롬프트]
2. ...
3. ...

## /cp prep 투입 기준
topics.csv에 추가할 키워드 및 의도:
[키워드1], [검색의도], [AI인용목표]
```

### Phase 4: 순환 추적 — `--track` 모드

**측정 스냅샷 저장 형식:**

```json
// GEO-BRAND-BASELINE-[YYYYMMDD].json
{
  "brand": "브랜드명",
  "date": "2026-05-07",
  "positioning_reflection": 32,
  "sov": 18,
  "bci": 24,
  "channel_citation": 0,
  "context_match": 44,
  "gap_grade": "DISTANT",
  "top_gaps": ["자동화 키워드 미연결", "자사 채널 인용 0%"]
}
```

**`--track` 실행 시 비교 출력:**

```
[ Gap 변화 추적 ]
측정 기간: 2026-05-07 → 2026-06-04 (28일)

                    이전      현재      변화
포지셔닝 반영률     32        51       +19 ↑
SOV                 18%       27%      +9% ↑
BCI                 24        38       +14 ↑
채널 인용률         0%        8%       +8% ↑
Gap 등급            DISTANT → PARTIAL  (1단계 개선)

개선된 Gap:
✓ "자동화" 키워드 → 담변 6건 중 3건에서 우리와 연결됨

남은 Gap:
→ 자사 채널 인용률 여전히 낮음 (8%, 목표 30%)
→ 추가 권고: [콘텐츠 주제 2개]
```
