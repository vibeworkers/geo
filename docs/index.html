Problems GEO helps solve

  • No clear GEO strategy, workshop plan, or learning structure yet.
  • Notes, briefs, drafts, files, and reports are scattered.
  • Reusable checklists, handouts, templates, or evidence notes are missing.
  • Optional execution work like audit, schema, report, or proposal is needed.

What is bundled

  • One shared geo <request> router contract.
  • Runtime guidance for Codex/ChatGPT, Claude, and Gemini.
  • Optional execution subskills under skills/*.
  • Workflow docs, setup hints, and troubleshooting guidance.
